# AdminAI X 🚀

**AI-Powered Civic Intelligence Platform**

AdminAI X is an AI-powered civic complaint management platform designed to help administrators and government department officers understand, prioritize, and manage citizen complaints efficiently.

## 🌟 Features

* 📝 Citizen complaint submission
* 🤖 AI-based complaint classification
* 📊 AI confidence prediction
* 🚨 Complaint priority prediction
* 🧠 AI-generated complaint summaries
* 👨‍💼 Admin dashboard
* 📈 AI analytics
* 👮 Department-specific officer portal
* 🔄 Complaint status management
* 💬 Officer remarks
* 🗄️ SQLite database

## 🤖 AI Technology

AdminAI uses Natural Language Processing (NLP) to analyze citizen complaint descriptions.

The classification pipeline uses:

* TF-IDF feature extraction
* Machine Learning
* Scikit-learn
* Linear SVM

The trained model predicts the relevant complaint category and provides confidence information.
